Questions fréquentes

Comment mes employés accèdent-ils à leur planning ?

Depuis l'app : Données → Mon compte. L'employé crée son compte, puis entre le code d'invitation que vous lui avez envoyé. Il voit alors uniquement son planning — jamais les salaires ni les informations des autres.

Comment envoyer un code d'invitation ?

Dans l'onglet Équipe, appuyez sur Envoyer à côté d'un employé, puis choisissez « Une invitation ». Un code à usage unique est généré et envoyé par SMS ou email.

Un employé peut-il voir les salaires ou les infos des autres ?

Non. Les employés voient seulement les prénoms et les horaires de leurs collègues. Les salaires, coordonnées et documents restent réservés au responsable.

L'app fonctionne-t-elle sans internet ?

Oui pour créer et consulter vos plannings. Internet est nécessaire uniquement pour la connexion aux comptes et la synchronisation entre appareils.

Comment supprimer mon compte ou mes données ?

Écrivez-nous à noamadar.noa@gmail.com avec l'objet « Suppression de compte ». Voir aussi notre politique de confidentialité.
